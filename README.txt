POKEFIELDS THEME STUDIO

THIS IS THE EDITOR BUNDLE
Do not import PokeFields-Theme-Studio-Package.zip into the game.
Extract it and open the HTML editor. Import a ZIP exported by the editor,
or import the included nintendo-field-green-ui.zip starter theme directly.

OPEN THE EDITOR
Open PokeFields-Theme-Studio.html with Firefox, Chrome, or Edge.
It is a standalone offline file. No installation, account, or API key is needed.
The studio has its own header and LeagueEnjoyer64 byline. The editor uses the SN Pro font,
UI icons from your game's resource dump and an original pixel mascot, Sprig.
The PC preview has a 10-by-6 storage grid.
Use Game original to see the game's default charcoal panels and blue selections.

MAKE YOUR COLORS
1. Choose a preset, or pick a palette group on the left.
2. Use the square to choose saturation and brightness. Use the rainbow rail for hue.
3. You can also enter RGB numbers or a hex value. Opacity controls transparency.
4. The "keep each control's existing transparency" option preserves different
   transparencies within a palette group. Changing opacity explicitly turns it off.
5. Use Every color to search all 1,675 colors in the included game-theme catalog (from the November 19, 2026 game dump).
   Every individual color has a component sample. The layouts are illustrative.
6. Optional corner rounding and border thickness apply to flat UI styles.

PREVIEW EVERY COLOR
Selecting a palette category shows a focused sample above the game preview.
All elements shows all 21 categories, including normal, hovered, selected and
focused buttons; tooltips; gold; IV/EV/nature/shiny highlights; PC slots; chat;
and healthy, medium and low HP in both battle and summary bars.
Expand Preview all matching colors to see each affected control and its exact RGBA.
Every color mode also shows an exact-property sample for each of the 1,675 entries.

CHOOSE YOUR FONT
Click Fonts in the header to search 1,916 families. You can also select a quick
font or open Browse all fonts in the UI font panel below the game preview.
Inter, Roboto, Nunito, Merriweather, JetBrains Mono, Pixelify Sans, Press Start 2P,
and VT323 are bundled and work offline. Other families download when selected.
Inside Fonts, Import your own font accepts a custom TTF/OTF file up to 8 MB.
The selected font is applied to the PC, chat, menu and component previews.
Download mod ZIP includes the actual font file and its license automatically.
It replaces assets/fonts/SNPro-Medium.ttf using the game's supported font override.
Save design keeps the selected font in your editable backup as well.
Large custom fonts may exceed browser autosave space; use Save design in that case.
Font catalog and licenses: https://github.com/google/fonts

SAVE YOUR DESIGN
The editor tries to save the design in this browser on this device.
Use Save design to download a portable editable JSON copy. Load design restores it.
If browser storage is unavailable, downloading the design still works.

INSTALL YOUR THEME MOD
1. Click Download mod ZIP. The ZIP filename is based on your theme name.
   The editor shows installation steps after downloading. Keep the file zipped.
2. At the PokeFields login screen, choose Mods, then Import Mod.
3. Select the exported ZIP. Enable the imported theme.
4. Place it below other theme/color mods so its overrides take priority.
5. Save and let the game restart. Theme colors load at startup.

SHARE YOUR THEME
Send the downloaded mod ZIP to other players. They can follow the same import
steps without installing the editor. The ZIP contains mod.json, theme.json,
and README.txt directly at its root; no extracting or manual repackaging is needed.

READY-MADE STARTER
nintendo-field-green-ui.zip is a ready-to-import green-and-gold theme.
It includes only mod.json, theme.json, and installation instructions.
To install it, follow the same Mods > Import Mod steps above.

UPDATING OR REMOVING
When replacing a design, disable the older theme before enabling the newer one.
Disable the theme in Mod Management and restart to return to the underlying theme.
This package does not modify the original game's installation files.

AFTER A GAME UPDATE
The game theme is included in the editor. No theme.json upload is required.
If a game update changes UI control names, use an updated version of Theme Studio.

LIMITS AND VERIFICATION
This is an external theme editor that exports a supported PokeFields theme mod.
It does not add a live RGB picker inside the game. Applying colors requires a restart.
The PC, chat, and menu previews use sample data and approximate the game's UI.
The starter theme and a browser-generated export passed the official pfmod v1.2 checker
with no skipped files and "theme loads". The editor passed automated browser checks
for its picker, hue, RGB/hex, opacity, presets, undo/redo, project save/load, ZIP export,
custom shapes, game-theme refresh, autosave, and mobile layout.
All 21 palette categories and all 1,675 exact-color samples were checked.
The font export passed the official checker with 1 file loaded, 0 skipped, and
theme loads. A font-only export was checked too. Font files and licenses are
included, and font save/reload, custom upload, undo and offline selection were tested.
The theme's actual appearance has not been tested in the running game.
